Any icon on the site. Tabler outline only — a second family reads as a different product.

```jsx
<Icon name="git-branch" size={26} />
<Icon name="sparkles" size={20} label="agent" />
```

Sizes: 16 inline, 20 nav, 26 feature. Keep stroke-width 2 at every size; never optically thin them, never fill them. An icon in marketing copy earns its place by naming a real surface — tree, branch, agent — never as decoration.
