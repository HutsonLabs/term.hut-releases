```jsx
<Card><Eyebrow>Badges</Eyebrow>…</Card>
<Card variant="dashed">…</Card>
```

`edge` swaps the flat hairline for the approved grey gradient border (feature cards only). `dashed` marks a state — an empty feed, a fetch failure — not a container.
