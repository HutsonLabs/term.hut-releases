term.hut

A local, agent-aware terminal for macOS.

PTY shell, file tree, LSP-backed editor, and a Claude Code chat panel in one window — working identically against a local directory or a remote host over SSH.

Download for macOS Other platforms latest release · Apple silicon · signed & notarized

why it exists

Detached agents that outlive the app

Claude sessions are not child processes. They run nohup'd behind a FIFO on whichever host owns them. Closing term.hut detaches; reopening — or another device over SSH — re-attaches, replaying the stream and then following it. The app is a viewer, not the owner.

Anchored workspaces

An anchored directory binds its own Claude session, terminal, editor, and git branch or worktree. Switching the anchor switches all of it at once, local or remote.

One surface

Terminal, file tree, LSP-backed editor, and agent chat share state in a single window rather than in juggled apps and panes.

Auth is inherited, never re-implemented: the spawned Claude Code CLI reads its own keychain and ~/.claude credentials, so term.hut contains zero Anthropic auth code.

ghcr.io/hutsonlabs/term.hut

Every release ships the same version three ways. The container image is built in the same CI run as the deb, from that exact deb, so the three artifacts on a release are always the same build. The macOS app updates itself in place after that.
