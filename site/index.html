term.hut

A calm agentic workspace

Terminal, files, code editor and chat share state in one window — against a local directory or ssh. Sessions run behind a FIFO on the host that owns them, so closing the app detaches instead of killing them.

Why it exists

stated as mechanisms, not benefits
01

Confusion

I kept getting confused when running multiple agents and repos: what was running where? I tried other apps, but they all had limitations that didn't work for me. I found I was using VSCodium the most, but it felt bloated. It inspired this app.

02

Curiosity

Could I design an app that met my criteria while also learning about Rust and Tauri? Could I keep it small, but useful? Could I use this for my business, personal, and technical amibition? I'm still trying to answer that question, but this is my start.

03

Claude

VSCodium paired Claude Code awesome harnesses. I wanted something smaller with only the stuff I found awesome or interesting. I try and keep it up to date with the latest from Claude Code to leverage any cool new stuff or avoid breaking anything.

Reuse, not remake

The build small by letting better tools do their thing. Also, term.hut works with Claude's subscription (important to me) and the same jsonl used with the .VSIX Anthropic release to reduce the likelihood of getting blocked.

What I won't do
  • Take your data.
  • Build for architectures I don't use.
  • Try to take over the world
